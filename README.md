# Experiment 7 – Weather Information Dashboard

## Aim
To develop a Weather Information Dashboard using JavaScript and Fetch API to retrieve weather information from an online API.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API
- Visual Studio Code

## Features
- Search weather by city name
- Retrieve city coordinates using geocoding
- Display current temperature
- Display feels-like temperature
- Display humidity and wind speed
- Show weather descriptions and icons
- Handle invalid cities and network errors
- Responsive desktop and mobile design

## Project Structure
```text
EXP7-Weather-Dashboard/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click and select Open with Live Server.
4. Ensure you have an internet connection.
5. Search for a city to view its current weather.

## API Used
Open-Meteo:
- Geocoding API: https://geocoding-api.open-meteo.com/
- Weather API: https://api.open-meteo.com/

No API key is required for this demonstration.

## Result
Successfully developed a responsive Weather Information Dashboard using HTML, CSS, JavaScript, and Fetch API.

## Note
Weather data requires an internet connection. Availability and accuracy depend on the external API.
